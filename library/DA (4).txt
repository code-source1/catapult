Overview: Dynamic Array: HLS tools do not support dynamic arrays because hardware designs cannot
manage data structures with unbounded size. Hence, dynamic array functions such as malloc() and
free() must be replaced with pre-allocated arrays.

Example of a Violation:
    void scale(int* data, int n) {
        data = new int[n];
        // data pointer reassigned dynamically
    }

Correction Example 1 uses caller-allocated buffer:
    void scale(int* data, int n) {
        // assume data points to static buffer of size N
        for (int i = 0; i < n; ++i) data[i] *= 2;
    }

Correction Example 2 uses template for size:
    template <int N>
    void scale_tpl(int data[N]) {
        for (int i = 0; i < N; ++i) data[i] *= 2;
    }
