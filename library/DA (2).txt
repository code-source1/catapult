# Error: $PROJECT_HOME/main.cpp(14): Unsupported language feature 'variable length array (VLA)' (CIN-15)
# Error: $PROJECT_HOME/main_c3.cpp(12): Unable to reduce array size for variable 'data_x', currently 1024 words (CIN-84)

Overview: Dynamic Array: HLS tools do not support dynamic arrays because hardware designs cannot
manage data structures with unbounded size. Hence, dynamic array functions such as malloc() and
free() must be replaced with pre-allocated arrays.

Example of a Violation:
    void build_matrix(int r, int c) {
        int mat[r][c];
        // variable length array is not supported
    }

Correction Example 1 uses compile-time constants:
    void build_matrix_const() {
        const int R = 4, C = 8;
        int mat[R][C];
        // use constants instead of VLA
    }

Correction Example 2 uses template parameters:
    template <int R, int C>
    void build_matrix_tpl() {
        int mat[R][C];
    }
    // Instantiate with build_matrix_tpl<4,8>();
