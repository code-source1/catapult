Dynamic Array: HLS tools do not support dynamic arrays because hardware designs cannot manage data structures with unbounded size. Hence, dynamic array functions such as malloc() and free() must be replaced with pre-allocated arrays.



Before Conversion: Dynamic Array
int main() {
    int size = 5;
    int* dynamicArray = new int[size]; // dynamic allocation

    // Initializing array
    for (int i = 0; i < size; i++) {
        dynamicArray[i] = i * 2;  // Example initialization
    }

    // Accessing elements
    for (int i = 0; i < size; i++) {
        std::cout << dynamicArray[i] << " ";
    }

    delete[] dynamicArray; // Important: deallocate memory
    return 0;
}

After Conversion: Static Array
In the static array version, you define the array with a fixed size at compile time. The memory allocation and deallocation is automatically managed by the compiler.
#include <iostream>

int main() {
    const int size = 5;
    int staticArray[size];  // static allocation

    // Initializing array
    for (int i = 0; i < size; i++) {
        staticArray[i] = i * 2;  // Example initialization
    }

    // Accessing elements
    for (int i = 0; i < size; i++) {
        std::cout << staticArray[i] << " ";
    }

    return 0;
}
