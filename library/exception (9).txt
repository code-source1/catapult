# Error: $PROJECT_HOME/check.cpp(15): out-of-bound array read 
# Error: $PROJECT_HOME/check.cpp(16): illegal shift amount 
# Error: $PROJECT_HOME/check.cpp(20): unsupported exception keyword 'try' 
# Error: Compilation aborted 

Overview: Exception-handling: Violations are reported when there are
out-of-bound array reads/writes and illegal shifts. Additionally,
whereas CPU programs use stack popping to handle exceptions, on ASIC,
exception-handling modules need to be built to deliver the termination
message to other modules.

Example of a Violation:
    int verify(int *buf) {
        int v = buf[buf[0]];  // double-index OOB
        try { return 1 << buf[1]; } catch(...) {}
    }

Correction Example 1 adds runtime checks:
    int verify_safe(int *buf, ExceptionUnit &eu) {
        int idx = buf[0];
        if (idx < 0 || idx >= BUF_SIZE) eu.raise_exception(STATUS_OOB_READ);
        int shift = buf[1];
        if (shift >= 32) eu.raise_exception(STATUS_ILLEGAL_SHIFT);
        return 1 << shift;
    }
