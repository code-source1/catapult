Overview: Dynamic Array: HLS tools do not support dynamic arrays because hardware designs cannot
manage data structures with unbounded size. Hence, dynamic array functions such as malloc() and
free() must be replaced with pre-allocated arrays.

Example of a Violation:
    void rotate(int n) {
        int* arr1 = new int[n];
        int* arr2 = new int[n];
        // swapping dynamic arrays
    }

Correction Example 1 uses two static arrays:
    void rotate() {
        const int N = 8;
        static int arr1[N], arr2[N];
        for (int i = 0; i < N; ++i) arr2[i] = arr1[i];
    }
