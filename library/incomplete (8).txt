T_Ref8
# Error: $PROJECT_HOME/main.cpp(34): expected a statement (CRD-127)
# Error: Compilation aborted (CIN-5)

Overview: Incomplete Statement: HLS tools generate a violation when
the switch/case statement does not completely cover the range of values
for the object used in conditional expressions. Considering the
uncovered values to complete the statement is needed.

Example of a Violation:
    #pragma hls_design top
    void drive_sel(uint3 sel, ac_int<4, false> &drive) {
      switch (sel) {
        case 2: drive = 4;
        case 5: drive = 10;
      }
    }
    // sel ∈ {0..7}, only 2 and 5 handled

Example of a Fix:
    #pragma hls_design top
    void drive_sel(uint3 sel, ac_int<4, false> &drive) {
      switch (sel) {
        case 2: drive = 4;
        case 5: drive = 10;
        default: drive = 0;
      }
    }
