Overview: Exception-handling: Violations are reported when there are
out-of-bound array reads/writes and illegal shifts. Additionally,
whereas CPU programs use stack popping to handle exceptions, on ASIC,
exception-handling modules need to be built to deliver the termination
message to other modules.

Example of a Violation:
    void append(char *dst, const char *src) {
        int len = strlen(dst);
        dst[len+10] = 'X';       // may exceed buffer
        if (dst[len] == '\\0') throw 1;
        uint32_t v = 1 << (len+32);
    }

Correction Example 1 adds length checks and hardware exception:
    void append_safe(char *dst, int dst_sz, const char *src, ExceptionUnit &eu) {
        int len = strnlen(dst, dst_sz);
        if (len+1 < dst_sz) dst[len] = 'X';
        else eu.raise_exception(STATUS_OOB_WRITE);
        if (dst[len] == '\\0') eu.raise_exception(STATUS_LOGICAL_ERROR);
    }
