# Error: $PROJECT_HOME/final.cpp(28): unsupported exception keyword 'catch' 
# Error: $PROJECT_HOME/final.cpp(29): out-of-bound array write 
# Error: $PROJECT_HOME/final.cpp(30): illegal shift amount 
# Error: Compilation aborted

Overview: Exception-handling: Violations are reported when there are
out-of-bound array reads/writes and illegal shifts. Additionally,
whereas CPU programs use stack popping to handle exceptions, on ASIC,
exception-handling modules need to be built to deliver the termination
message to other modules.

Example of a Violation:
    void process(int *data) {
        try { /* ... */ } catch(...) {}   // unsupported
        data[16] = 0;                     // data size is 16
        uint32_t m = 1 << 64;             // shift too large
    }

Correction Example 1 builds exception module:
    void process_safe(int *data, ExceptionUnit &eu) {
        if (16 < DATA_SIZE) data[16] = 0; else eu.raise_exception(STATUS_OOB_WRITE);
        if (64 >= 32) eu.raise_exception(STATUS_ILLEGAL_SHIFT);
    }
