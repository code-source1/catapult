# Error: $PROJECT_HOME/state.cpp(40): unsupported exception keyword 'throw' (CIN-110)
# Error: $PROJECT_HOME/state.cpp(41): out-of-bound array write (CIN-102)
# Error: $PROJECT_HOME/state.cpp(42): illegal shift amount (CIN-103)
# Error: Compilation aborted (CIN-5)

Overview: Exception-handling: Violations are reported when there are
out-of-bound array reads/writes and illegal shifts. Additionally,
whereas CPU programs use stack popping to handle exceptions, on ASIC,
exception-handling modules need to be built to deliver the termination
message to other modules.

Example of a Violation:
    void update_state(int *state) {
        state[8] = 1;         // state size is 8
        if (state[0] == 0) throw 0;
        state[1] <<= 40;      // shift too large
    }

Correction Example 1 wires exception module:
    void update_state_safe(int *state, ExceptionUnit &eu) {
        if (8 < STATE_SIZE) state[8] = 1; else eu.raise_exception(STATUS_OOB_WRITE);
        if (state[0] == 0) eu.raise_exception(STATUS_INVALID_STATE);
        if (40 >= 32) eu.raise_exception(STATUS_ILLEGAL_SHIFT);
    }
