# Error: $PROJECT_HOME/math.cpp(30): illegal shift amount 
# Error: $PROJECT_HOME/math.cpp(31): out-of-bound array write 
# Error: $PROJECT_HOME/math.cpp(35): unsupported exception keyword 'try' 
# Error: Compilation aborted 

Overview: Exception-handling: Violations are reported when there are
out-of-bound array reads/writes and illegal shifts. Additionally,
whereas CPU programs use stack popping to handle exceptions, on ASIC,
exception-handling modules need to be built to deliver the termination
message to other modules.

Example of a Violation:
    void shift_and_store(int *arr) {
        int x = 1 << 33;    // shift beyond bitwidth
        arr[5] = x;         // assume arr has only 4 elements
        try { /* ... */ } catch (...) {}  // unsupported
    }

Correction Example 1 splits shifts and uses exception unit:
    void shift_and_store_safe(int *arr, ExceptionUnit &eu) {
        int x = (33 < 32) ? (1 << 33) : 0;
        if (33 >= 32) eu.raise_exception(STATUS_ILLEGAL_SHIFT);
        if (5 < 4) arr[5] = x; else eu.raise_exception(STATUS_OOB_WRITE);
    }
