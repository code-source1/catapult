Optimization targets: Large latency
UNROLL

Description

Beginner Level

The UNROLL directive specifies how many times to unroll a loop.

The example gives a practical application of the directive on a design. Catapult applies the UNROLL directive explicitly on any loop. As mentioned in the example, the UNROLL is set to a specific integer. In the first solution (test.v1), the loop is left fully rolled and only a single multiplication is performed in C-step C1.

IMAGE

In the second solution (test.v2), the loop is unrolled by 2, and two multiplications are performed in C-step C1.

Command syntax example:
directive set /test/core/main/MAC -UNROLL 2

Why this target fits:
UNROLL duplicates loop hardware so multiple iterations can execute in parallel. This can reduce
latency or improve throughput, but usually increases area and power. Therefore it is a direct
template for Large latency, not for Large area or High power.
