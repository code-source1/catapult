BOUNDARY_OPT

Description

Beginner Level

The BOUNDARY_OPT directive controls whether Catapult propagates constants across top-down CCORE interfaces.

In the first solution (test.v1), the UNIQIFY directive is set to none, and BOUNDARY_OPT is set to false. As a result, Catapult synthesizes a single CCORE which is visible in the schematic:

IMAGE

The second solution (test.v2) sets UNIQIFY to auto and BOUNDARY_OPT to true. As a result, Catapult synthesizes a CCORE for every call to the tcore function in the unrolled loop, taking advantage of constant propagation across hierarchical boundaries. The schematic reveals four individual CCOREs.

Command syntax example:
directive set -BOUNDARY_OPT false
directive set /test/tcore -BOUNDARY_OPT true
