DESIGN_GOAL

Description

The DESIGN_GOAL directive sets the scheduling optimization goal (area versus latency).

In the first solution (test.v1), the default value of the directive is area. Catapult attempts to reduce the area of the design while meeting the design constraints. The following illustration shows the resulting schedule for the first solution using the default values:
